# GDAL and GRASS GIS Scripts — Topographic and Geophysical Modelling of the Okinawa Trough

GDAL utility and GRASS GIS shell scripts used to produce the figures in the peer-reviewed article by Polina Lemenkova. The scripts perform topographic and geophysical modelling of the Okinawa Trough and Ryukyu trench-arc system (southern Japan, East China Sea and Philippine Sea, West Pacific Ocean) from the GEBCO DEM (NetCDF, 15 arc-second resolution).

**Published in:** *Podzemni Radovi / Underground Mining Engineering* **2021**, (38), 87–100
**DOI:** https://doi.org/10.5937/podrad2138087L

## Contents
Shell scripts using GDAL utilities (gdalinfo, gdalwarp for UTM reprojection, gdaldem for roughness, Topographic Position Index (TPI), Terrain Ruggedness Index (TRI), hillshade, aspect and colour relief) and GRASS GIS (r.in.gdal, r.info, r.timestamp) to model topography, surface roughness, terrain indices, gravity and geoid grids over the Okinawa Trough.
